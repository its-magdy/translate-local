# Placeholder sentinels ride the glossary tag channel

File mode, and text mode since `TranslationSession.translate()` masks placeholders, sends each placeholder sentinel to the model as a glossary hit whose source and target are the sentinel itself (`sentinelHits()` in `files/placeholders.ts`), so it is wrapped in a `<term>` tag like a real term. TranslateGemma copies tagged text much more reliably than it follows an instruction to keep bare tokens. The fake hits also do work at the adapter seam: a non-empty `request.glossaryHits` is what makes `buildStructuredPrompt` add its term-tag rule, which a leaf with placeholders but no glossary term still needs. So we don't give sentinels a separate "verbatim" input. Inside core they are already kept apart: `TermSet` takes real hits and these extra hits as separate arguments, and only real hits count toward coverage, reminders, retries, the tag check and the repair. The checks that still single sentinels out (in the tag strip, the tag check and the prompt's token counter) come from the tag format, so they would stay with any input shape.
